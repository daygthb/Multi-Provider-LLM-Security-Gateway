# Multi Provider LLM Security Gateway Implementation Plan

> **For agentic workers:** Use the implementation skill to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver the complete gateway specified in `docs/specification.md`, with reproducible local verification.

**Architecture:** FastAPI composes hashed-key SQLite identity storage, Redis atomic quota reservations, YAML policy evaluation, and HTTP provider adapters through dependency injection. Secure streaming buffers upstream content before releasing SSE so response policies can inspect secrets spanning chunks. A credential-free demo explicitly selects an in-memory quota backend; production fails closed when Redis is unavailable.

**Tech Stack:** Python 3.12, FastAPI, Pydantic Settings, HTTPX, aiosqlite, Redis Lua, Prometheus, pytest, Ruff, mypy, Docker Compose, Kubernetes.

**Spec:** `docs/specification.md`

## Global Constraints

- OpenAI-compatible chat requests and JSON/SSE responses; adapters for OpenAI, Ollama, deterministic mock.
- Hash-only high-entropy API keys, tenant/model/permission restrictions, revocation CLI.
- Atomic per-key RPM/TPM and per-tenant monthly budgets; fail closed on infrastructure errors.
- YAML-driven heuristic security policies and response protection; never promise guaranteed security.
- No complete prompts, credentials, or response content in audit logs or dashboard.
- Bounded requests/responses, retries, timeouts, circuit breakers, health and fallback/cost routing.
- Tests, Ruff, mypy, dependency scan and Docker build in CI; coverage minimum 85%.
- Verify real commands and demo; distinguish unavailable deployment tools from tested behavior.

## Review Focus

1. Concurrent reservations across keys of one tenant must not overspend the monthly budget.
2. Encoded or split secret content must not escape response scanning through SSE boundaries.
3. Cancellation and upstream failure must finalize quota reservations conservatively.
4. Corrupt upstream responses and exhausted providers must yield sanitized consistent errors.
5. Revoked keys and cross-tenant model access must fail without logging bearer values.
